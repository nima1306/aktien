Bot

Läuft automatisch Mo–Fr morgens. Zum Starten per Knopf einmal in den Einstellungen (⚙︎) einen GitHub-Schlüssel eintragen.

Bot per Knopf starten

  1. Auf github.com: Profilbild → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → dein Aktien-Projekt.
  3. Permissions → Repository permissions → Actions: Read and write. Erstellen und den Schlüssel hier einfügen.

Der Schlüssel bleibt nur auf diesem Gerät gespeichert und kann nur Abläufe in diesem einen Projekt starten.
